# ♻️ Recicla Game

O **Recicla Game** é um jogo educativo interativo desenvolvido para ensinar crianças e a comunidade escolar sobre a importância da reciclagem e o descarte correto de resíduos. 

---

## 🎯 Sobre o Projeto

O projeto foi criado com o objetivo de unir tecnologia e educação ambiental. Através de mecânicas simples e visuais interativos, os jogadores aprendem a separar diferentes tipos de lixo (papel, plástico, vidro, metal e orgânico) em suas respectivas lixeiras.

---

## 🚀 Tecnologias Utilizadas

* **React.js:** Construção da interface e componentes do jogo.
* **JavaScript (ES6+):** Lógica das mecânicas, pontuação e regras.
* **CSS3 / Styled Components:** Estilização e animações visuais.
